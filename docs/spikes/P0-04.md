# P0-04: MODEL_FAMILIES measured against the documented routing strings

## Method

Searched `docs/routing.md`, `templates/kukulu.config.example.json`,
`templates/ccr/*.json`, `docs/SPEC.md`, `agents/*.md`,
`docs/flights/*/SUMMARY.md` and `docs/flights/*/PLAN.md` for `model` lines,
`provider/model` forms and the family names. Each distinct string was
classified with `familyOf`, and every one was added to
`test/fixtures/families.json`, which `test/cleanroom.mjs` loops over.

non-Anthropic, so a family table that called them `claude` would disagree with
runner resolution.

## Before and after

routing string that plainly belongs to a listed family landed in `unknown:`,
so no pattern was widened. The three `unknown:` rows are mistakes recorded in
the flight reports, not routing strings.
